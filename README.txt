PUBLISH ON GITHUB PAGES:
1. Download and extract the ZIP.
2. Open your GitHub repository: wabui-nelson-website.
3. Delete or replace the old index.html. Upload ALL files and folders from this extracted folder into the repository root (not the ZIP itself).
4. Commit the changes.
5. Open Settings > Pages and ensure GitHub Pages is deploying from main / (root).
6. Visit your site after deployment finishes.
